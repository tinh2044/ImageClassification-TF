# Contributing to Tensorflow - Image Classification

First off, thank you for considering contributing to **Tensorflow - Image Classification**! Your contributions help make this project better for everyone.

## 🤝 How to Contribute

There are several ways you can contribute:

- **Reporting Issues:**  
  If you find a bug or have ideas for improvements (including new models or features), please [open an issue](https://github.com/tinh2044/ImageClassification-TF/issues) and provide as much detail as possible, including:

  - A clear description of the issue or enhancement.
  - Steps to reproduce the bug (if applicable).
  - Any error messages or logs.
  - Your operating system, Python version, and TensorFlow version.

- **Feature Requests:**  
  Got an idea to improve the project? Please open an issue and label it as a feature request. Include:

  - A clear description of the proposed feature.
  - Its potential benefits to users.
  - Any references (e.g., research papers or similar projects) that could help in the implementation.

- **Pull Requests:**  
  We welcome pull requests! To ensure a smooth review process, please follow these guidelines:
  1. **Fork the Repository:** Create your own fork and clone it locally.
  2. **Create a Branch:** Make your changes on a dedicated branch. For example:
     ```bash
     git checkout -b feature/your-feature-name
     ```
  3. **Code Style & Documentation:**
     - Follow the existing code style and conventions.
     - Write clear, maintainable code and add comments where necessary.
     - Update or add documentation if your change affects usage.
  4. **Testing:**
     - Make sure your changes do not break existing functionality.
     - Add tests for any new features, if applicable.
  5. **Commit Messages:**
     - Use clear, concise commit messages in the imperative mood (e.g., "Add new MobileNetV3 support").
  6. **Submit Your PR:**  
     Once your changes are ready, push your branch to your fork and open a pull request on GitHub. Please reference any related issues in your PR description.

## 🛠️ Development Guidelines

- **Code Quality:**  
  Write code that is clear and maintainable. Follow the style and structure used throughout the repository.
- **Testing:**  
  Run existing tests to ensure nothing is broken, and add tests for new features if possible.
- **Documentation:**  
  Keep documentation up-to-date. If you make changes to functionality or add new features, update the README or related docs accordingly.

## 📚 Getting Started Locally

1. **Fork** this repository.
2. **Clone** your fork:
   ```bash
   git clone https://github.com/tinh2044/ImageClassification-TF.git
   cd ImageClassification-TF
   ```
3. **Create a new branch:**
   ```bash
   git checkout -b feature/your-feature-name
   ```
4. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
5. **Make your changes**, commit them, and push your branch:
   ```bash
   git commit -am "Add a short description of your changes"
   git push origin feature/your-feature-name
   ```
6. **Open a Pull Request** on GitHub.

## 📄 Code of Conduct

This project adheres to the [Contributor Covenant Code of Conduct](https://www.contributor-covenant.org/). Please review it to understand the expected behavior for all contributors. If you encounter any issues or have concerns, please report them to the repository maintainers.

## ❓ Questions?

If you have any questions or need help, feel free to open an issue or reach out to one of the repository maintainers.
